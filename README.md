# Break Reminder (Plan)

## Goal
A simple Python program that shows a pop-up reminder every so often, and stops when you click Stop.

## How it should work (no code yet)
1. The program starts and asks for minutes.
   - Press Enter to use the default: 30 minutes.
   - Type a number to use a different time.
2. The program converts minutes to seconds.
3. The program repeats forever:
   - Wait for the chosen time.
   - Show a pop-up: "Time for a break!"
   - Two buttons: OK and Stop.
   - OK closes the pop-up and keeps the timer running.
   - Stop ends the program completely.

## Beginner-friendly choices
- Use terminal input for the time (simpler than a custom input box).
- Use a simple built-in Python window system for the pop-up.
